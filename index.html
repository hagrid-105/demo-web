11. 折叠面板 Accordion

什么是 HTML？
HTML (HyperText Markup Language) 是构建网页的标准标记语言，用于描述网页的结构。HTML 元素是网页的构建块，由标签表示。
什么是 CSS？
CSS (Cascading Style Sheets) 是一种样式表语言，用于描述 HTML 文档的呈现方式。CSS 控制布局、颜色、字体和响应式设计。
什么是 JavaScript？
JavaScript 是一种高级编程语言，使网页具有交互性。结合 ECharts 等库，可实现动态数据可视化。
